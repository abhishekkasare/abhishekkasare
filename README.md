## 👨‍💻 About Me

I'm **Abhishek Kasare**, a **DevOps & Cloud Engineer with 4+ years of professional experience**, passionate about building scalable infrastructure, automating deployments, and improving application reliability.

I enjoy working across **cloud infrastructure, containerization, CI/CD, Kubernetes, Infrastructure as Code, monitoring, and automation**.

I believe in understanding the fundamentals behind the technologies I use and continuously improving my skills through hands-on projects and real-world problem solving.

- 🏗️ Automate infrastructure using **Terraform**
